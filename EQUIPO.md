-----------------------------------------------------------------
	   2. Metodología y Organización para las Entregas
-----------------------------------------------------------------


Control de Versiones (Gitflow Estricto): Se trabaja exclusivamente mediante ramas de características (feature/) individuales. Ningún integrante hace modificaciones directas sobre develop o main, los cambios se integran únicamente mediante Pull Requests revisados para mantener una total coherencia con los commits del repositorio.

Gestión de Tareas: Uso de CLICK UP para asignar historias de usuario y tareas técnicas por cada iteración.

Sincronización: Breves reuniones para coordinar cada integración mayor para alinear los contratos de las API entre el backend y las interfaces de usuario.
